# SmartBill – Android Billing Application

SmartBill is an Android application intended to help small business owners manage products and create bills digitally.

## Features

- Add and manage products with their prices
- Select products and calculate bill totals
- Adjust item quantities
- Apply discounts
- Store product and bill information locally using SQLite
- Display a QR code for payment
- Share bill details through WhatsApp

## Technology Stack

- **Language:** Java
- **IDE:** Android Studio
- **User interface:** XML
- **Local database:** SQLite

## Getting Started

1. Clone or download this repository.
2. Open the project in Android Studio.
3. Allow Gradle to sync and download the required dependencies.
4. Start an Android emulator or connect an Android device.
5. Run the app from Android Studio.

## Project Goal

SmartBill aims to make everyday billing easier for small shops by providing a simple mobile-based billing workflow.
